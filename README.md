# wb-mqtt-dmx

Сервис для контроллеров Wiren Board, который выдаёт DMX512 прямо с порта RS-485 контроллера или
модуля WBE2 RS-485 и публикует световые приборы как MQTT-устройства.

## Зачем это нужно

Без сервиса DMX-свет подключают к контроллеру через отдельный шлюз, например Modbus-DMX или
Art-Net-узел. Шлюз нужно купить, запитать, настроить своей утилитой, а каналы DMX вручную описать
в контроллере как регистры или сырые каналы. Что стоит за каналом 17, знает только тот, кто
настраивал.

1. **Шлюз не нужен.** Линия DMX подключается к клеммам RS-485 контроллера или модуля расширения.
2. **Приборы вместо номеров каналов.** Прибор описывается одной строкой раскладки, например `drgbw`
   для диммера и четырёх цветов. В веб-интерфейсе и правилах появляется устройство с каналами
   «Диммер», «Красный», «Зелёный», а не «канал 17».
3. **Настройка в веб-интерфейсе контроллера.** Порты, приборы и адреса задаются в форме
   «Выход DMX512», без файлов и сторонних утилит.
4. **Одинаковые приборы одной строкой.** Количество больше одного даёт приборы на адресах подряд и
   групповое устройство, которое управляет всеми сразу.
5. **Свет переживает перезапуск.** Выставленный свет возвращается после сохранения настроек,
   перезагрузки и отключения питания. Значения пишутся на диск, только когда свет замер, поэтому
   бегущая сцена ресурс флеш-памяти не расходует. Восстановление можно выключить в настройках порта.
6. **Световой пульт может перехватить управление.** Пульт или программа в сети управляют портом по
   Art-Net или sACN; когда они замолкают, порт возвращается к значениям из MQTT.

## Установка

```bash
apt update && apt install wb-mqtt-dmx
```

Поддерживаются релизы Wiren Board на Debian trixie.

## Подключение

| Клемма контроллера | Контакт XLR | Сигнал DMX |
|---|---|---|
| A | 3 | Data+ |
| B | 2 | Data− |
| GND | 1 | общий |

Приборы соединяются цепочкой, на последнем ставится терминатор 120 Ом. Если при нулевых значениях
приборы мигают, а при любых других горят всеми цветами сразу, перепутаны A и B.

## Настройка

1. Освободите порт: в веб-интерфейсе откройте *Настройки → Конфигурационные файлы → Настройка
   драйвера serial-устройств* и отключите порт, к которому подключён DMX. Пока порт включён там,
   сервис его не откроет и напишет об этом в состоянии.
2. Откройте *Настройки → Конфигурационные файлы → Выход DMX512*, выберите вкладку порта и поставьте
   галочку «Включён».
3. Добавьте приборы в таблицу. У каждой настройки в форме есть подпись: что она делает, когда её
   менять и какое значение по умолчанию.

Раскладка прибора — по одной букве на канал DMX в том порядке, в каком они идут у прибора:

| Буква | Канал | Буква | Канал |
|---|---|---|---|
| `d` | диммер | `u` | ультрафиолет |
| `r` `g` `b` | красный, зелёный, синий | `c` | холодный белый |
| `w` | белый | `h` | тёплый белый |
| `a` | янтарный | `s` | строб |
| `m` | режим (канал выбора программы) | `_` | канал не используется |

Пример: прожектор с каналами «яркость, красный, зелёный, синий, белый, программа, скорость» — это
`drgbwms`, он занимает семь адресов. Для приборов, которые не описать буквами, есть тип «Каналы»:
N простых каналов.

## Что появляется в MQTT

- `dmx_<идентификатор>` на каждый прибор, с каналом на каждую букву раскладки. Идентификатор
  строится из названия: «Фасад» → `dmx_fasad`. У приборов из одной строки с количеством больше
  одного добавляется номер, а устройство без номера управляет всеми сразу.
- `wb-mqtt-dmx` — состояние сервиса и каждого порта: работает ли порт, частота кадров, карта
  адресов, кто сейчас управляет портом, кнопка «Погасить всё».

## Приём Art-Net и sACN

В настройках порта включите нужный протокол и задайте номер вселенной. Пока пульт шлёт данные, на
линию идут его кадры, а каналы приборов показывают его значения. Через несколько секунд после
остановки пульта порт возвращается к значениям из MQTT. Оба протокола по умолчанию выключены: у них
нет защиты, и включённый приём позволяет управлять светом любому устройству в сети.

## Если прибор мерцает или не реагирует

1. Проверьте адрес и режим каналов на самом приборе: раскладка должна совпадать с его режимом.
2. Снизьте частоту кадров порта до 25–30.
3. В разделе «Дополнительно» увеличьте BREAK до 250–400 и MAB до 50–100.
4. Задайте паузу между каналами, начиная с 20 мкс. Частота кадров при этом падает, подробности в
   подписи к настройке.

Проверить порт без MQTT и настроек можно тестовым сигналом:

```bash
systemctl stop wb-mqtt-dmx
wb-mqtt-dmx test-port /dev/ttyRS485-2 --pattern blink --seconds 30
```

`blink` раз в секунду включает и гасит все каналы, `full` держит все на максимуме, `ramp` выдаёт в
канал N значение N. В конце команда печатает число кадров, частоту и число опоздавших кадров.

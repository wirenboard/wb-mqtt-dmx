# Шаблоны приборов

Базовый набор пуст: простые приборы описываются строкой раскладки (тип «Раскладка»),
сложные — JSON-файлами в этом формате (см. docstring в `wb/mqtt_dmx/templates.py`). Пользовательские
файлы кладутся в `/etc/wb-mqtt-dmx.conf.d/templates/`, после чего `wb-mqtt-dmx update-schema`.

# Тесты

## Как запустить

Из корня репозитория, с подтянутым сабмодулем библиотеки MQTT:

```bash
git submodule update --init
python3 setup.py --quiet egg_info && pytest
```

Первый шаг создаёт метаданные пакета: тесты версии читают версию из них. При сборке пакета то же
делает `debian/rules`.

## Что нужно

`python3-pytest`, `python3-jsonschema`, `python3-asyncio-mqtt` и `mosquitto`. Проще всего запускать на
контроллере или в devenv для trixie: там стоят те же версии, что при сборке.

Контроллер, стенд и линия DMX **не нужны**. Последовательный порт заменён заглушкой из `fakes.py`: она
записывает каждый вызов и ведёт свои часы, поэтому тесты ничего не ждут. Сетевые пакеты Art-Net и sACN
собираются в `packets.py` так, как их шлёт пульт.

Общий MQTT-брокер тоже не нужен. Тесты из `test_mqtt.py` запускают каждый свой `mosquitto` на свободном
порту: брокер настоящий, потому что заглушка библиотеки MQTT повторяла бы наши же представления о ней.
Если программы `mosquitto` на машине нет, эти тесты пропускаются, остальные идут как обычно.

Библиотека MQTT лежит сабмодулем в корне репозитория, а в пакет попадает как `wb.mqtt_dmx.wb_mqtt_lib`.
В исходниках такого модуля нет, поэтому `conftest.py` загружает её под этим именем из сабмодуля.

Тесты формы читают два файла из корня репозитория: `wb-mqtt-dmx.conf` и `wb-mqtt-dmx.schema.json`.
При сборке пакета `debian/rules` кладёт их рядом с тестами и убирает после.

## Что покрыто

| Файл | Модуль | Что проверяет |
|---|---|---|
| `test_dmx_port.py` | `dmx_port` | настройку линии 250000 8N2, удержание передатчика, возврат порта в исходное состояние, состав кадра, паузу между каналами |
| `test_sender.py` | `sender` | буфер каналов, поток кадров, отчёт об ошибке порта, период кадров с паузой и без |
| `test_templates.py` | `templates`, `controls` | разбор раскладки по буквам, 16 бит, неиспользуемые каналы, тип «Каналы», значения каналов в байты и обратно |
| `test_ids.py` | `ids` | идентификатор из названия, суффиксы при совпадении |
| `test_config.py` | `config` | адреса приборов, группы, идентификаторы, сетевые вселенные, отказ на каждую ошибку конфигурации с её текстом |
| `test_netin.py` | `netin` | разбор Art-Net и sACN, ответ на поиск узлов, выбор источника по приоритету, таймауты, раздачу вселенных по портам |
| `test_schema.py` | `schema` | совпадение файла схемы с модулем, корректность схемы и конфига из пакета, подписи и переводы, отсутствие скрытых и обязательных настроек |
| `test_service.py` | `service` | список устройств и их значения, запись в каналы и группы, «погасить всё», сохранение значений только когда свет замер и изменился, восстановление, перехват порта пультом и возврат, конфликт с драйвером serial |
| `test_mqtt.py` | `mqtt` | на настоящем брокере: устройства появляются и исчезают при остановке, запись доходит до линии и возвращается значением, кнопка «Погасить всё», отметка ошибки на устройствах нерабочего порта, уборка устройств после убитого запуска, ошибка настроек на устройстве сервиса |
| `test_main.py` | `main` | коды выхода при ошибках конфигурации, тестовые сигналы `test-port` |
| `test_version.py` | `version`, `main` | формат версии и флаг `--version` |

Доктесты модулей пакета запускаются тем же `pytest`.

## Если изменили форму настройки

Файл `wb-mqtt-dmx.schema.json` собирается из `wb/mqtt_dmx/schema.py`:

```bash
python3 -m wb.mqtt_dmx.schema > wb-mqtt-dmx.schema.json
```

Пока файл и модуль расходятся, `test_shipped_schema_file_matches_the_module` падает.
